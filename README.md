## 1. Project Overview
This repository contains the end-to-end Data Analytics Capstone Project analyzing transactional performance for a multi-category retail platform. The workflow covers the full analytics lifecycle:
1. Version control setup and repository management with Git/GitHub.
2. Data preparation, hygiene checks, and missing value handling using Python (Pandas).
3. Exploratory Data Analysis (EDA) and distribution plotting using Seaborn and Matplotlib.
4. Interactive executive dashboard development in Microsoft Power BI.
5. Extracting commercial insights and actionable business recommendations.
